PKSMG9 cloud build (no install on your PC)

1. Make a free account on https://github.com
2. Click + (top right) -> New repository. Name: pksmg9-build. Public. Create.
3. On the new repository page click "uploading an existing file".
4. Drag the folders ".github" and "PKSMG9-changes" from this ZIP into the page.
   (If ".github" is hidden on Windows: File Explorer -> View -> Show -> Hidden items.)
5. Click "Commit changes".
6. Open the "Actions" tab -> "Build PKSMG9 CIA" -> "Run workflow" (green button).
7. Wait about 10-20 minutes. Open the finished run, scroll down to "Artifacts", download "PKSMG9".
8. If the run turns red, open it, copy the last red lines and send them to Claude.
